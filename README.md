# ShowBuz landing page

Marketing site for **ShowBuz** — diary for chairs and deps, designed by musicians.

Built with Next.js, Tailwind CSS, and TypeScript.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s on the page

- Hero with product pitch and store download buttons
- Feature grid (calendar sync, booking, privacy)
- Download call-to-action
